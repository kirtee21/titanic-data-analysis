
# Titanic Data Analysis

This project performs data analysis on the Titanic dataset using Python.

## Features
- Load the Titanic dataset using Pandas
- Clean the dataset by handling missing values
- Explore and analyze passenger data
- Find survival statistics by gender and passenger class
- Analyze survival rate by age group
- Visualize data using Matplotlib and Seaborn
  - Bar Chart of Survival by Gender
  - Bar Chart of Survival by Passenger Class
  - Histogram of Passenger Ages

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
